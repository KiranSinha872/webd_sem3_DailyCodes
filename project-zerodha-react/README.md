# Zerodha Navbar & Hero Section (React + Vite)

A beginner-friendly React project recreating the **Navbar** and **Hero section** of the Zerodha website.

Follows the exact project structure, concepts, and styling practices from **L03 React Components**.

## Project Structure

```
zerodha-react-clone/
│
├── public/
│   └── favicon.svg
│
├── src/
│   ├── assets/
│   │   ├── landing.png
│   │   ├── landing.svg
│   │   └── logo.svg
│   ├── App.css
│   ├── App.jsx
│   ├── Hero.jsx
│   ├── index.css
│   ├── main.jsx
│   └── Navbar.jsx
│
├── .gitignore
├── eslint.config.js
├── index.html
├── package.json
├── package-lock.json
├── README.md
└── vite.config.js
```

## Running the Project

```bash
npm install
npm run dev
```
